# Contributing

Contributions are under Apache-2.0 and require Developer Certificate of Origin
sign-off. Preserve upstream attribution. Read AGENTS.md, the accepted contracts
and owning requirements before changing behavior. Run `python3 -B tools/check.py`.
Never commit weights, runtime binaries, credentials or live environment data.
Changes to authority, transport or lifecycle require the integration design gate.
